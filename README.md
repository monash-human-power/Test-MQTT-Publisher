# Monash Human Power - Test MQTT Publisher

A basic python script that simulate the phone that publishes the to the MQTT Broker

## How to use

### Requirements

- Need paho-mqtt module installed
- A broker to connect to use mosquitto or something for a local mqtt server

### Running the script

- Run it with CLI
- Enter values where prompted
- That's it
